## 📌 Описание

Данный репозиторий содержит код для воспроизведения космологических предсказаний теории **ТМДВ‑4.1**, описанной в статье:

> TS_Lvov, *Теория динамического темпа с калибруемыми временными направлениями (ТМДВ‑4.1)*, 2026.

Код вычисляет эволюцию полей `T₂` и `T₄`, решает модифицированное уравнение Фридмана и строит уравнение состояния тёмной энергии `w(z)`.

### Основные параметры модели

| Параметр | Значение |
|----------|----------|
| \( w_0 \) | -0.813 |
| \( w_a \) | -0.383 |
| \( T_{20} \) | 0.010 |
| \( T_{40} \) | 1.000 |
| \( z_{\text{sym},4} \) | 1.27 |
| \( z_{\text{sym},2} \) | 1000 |
